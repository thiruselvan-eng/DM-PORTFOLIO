# THIRU.MARKETING — Premium Digital Marketing & Creative Agency Website

An award-winning caliber portfolio website for **Thiruselvan M** (**THIRU.MARKETING**), showcasing digital marketing, on-location video shooting, reels editing, creative design, and website development services.

Engineered with **React + Vite**, **Tailwind CSS**, and **Framer Motion**, featuring a premium dark navy aesthetic (`#0B1020`), electric lime accents (`#A3E635`), Space Grotesk display headings, and Inter body typography.

---

## 🎨 Creative Art Direction & Visual Identity

- **Background Palette**: Deep studio navy (`#0B1020`), card surface (`#11182A`), elevated panels (`#162038`).
- **Accent**: Electric lime (`#A3E635`) with soft ambient glows (`rgba(163, 230, 53, 0.25)`).
- **Typography**: 
  - Headings: `Space Grotesk`, sans-serif (responsive `clamp()` font scaling).
  - Body: `Inter`, sans-serif.
  - Badges & Codes: Monospace tracking (`font-mono`).
- **Textures**: Subtle studio noise filter, dot-matrix grids, and camera viewfinder HUD elements (`hud-corner`).

---

## 📱 Mobile-First Responsive Standards

Optimized for viewports from **320px to 1440px+**:
- **No horizontal overflow** (`overflow-x-hidden`, zero clipped text).
- **Touch targets** meet or exceed the 44px standard (`min-h-[48px]`).
- **Hero mobile composition**: Communicates the brand and services immediately without excessive scrolling.
- **Responsive navigation**: Compact mobile header with an animated full-screen drawer and background scroll lock.

## 🚀 Running Locally

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Start local Vite development server
npm run dev
```

Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

---

## 📦 Production Build & Testing

```bash
# Build for production
npm run build

# Preview the production build locally
npm run preview
```
